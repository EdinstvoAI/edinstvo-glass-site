Design with the Glass effect built into Figma, then ship with this package. Most settings share a name, so the handoff is a short list of values.

How to use it

Select a layer, add the Glass effect in the Effects panel and lower the fill opacity. Every layer keeps its own values.

Settings

These are starting values. The two renderers differ, so check the result on the real backdrop and adjust by eye.

Only in the package

Figma has no match for bloom, rim, glint, lift or any motion setting. Leave the defaults and tune them in the playground.

With Claude

The Figma repository has a Claude skill with this table. Connect the Figma MCP server, copy the skill to your skills folder and ask Claude to turn a frame into code.

cp -r skills/edinstvo-glass-figma ~/.claude/skills/

Shader

For a live lens with the look of the package there is a shader effect. Add it to a frame and it sees everything inside that frame. Move the lens with the handle on the canvas.

The shader sees the frame as one flat picture, so it can't tell objects apart. One effect is one lens. For a second lens, wrap the frame in another frame. The shader isn't in the Community yet, its source is in the same repository.
