TagWhat it is

Element API

MemberWhat it does

sourceOne of "auto", a selector, an image, video or canvas
invalidate()Redraw on the next frame
show(), hide()Appear and vanish, both return a promise

AttributeWhat it does

CSS variables

--glass-radius, --glass-shadow, --glass-tint, --glass-fallback, plus --glass- and the name of any numeric setting.
