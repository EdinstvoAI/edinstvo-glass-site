Everything the package gives you, with an example for each part. You don't need to know web components to read this.

Three words first

An attribute is written in HTML, inside the tag. A property is the same kind of setting, set from JavaScript on the element. A method is a function you call on the element to make it do something.

Tags

Importing @edinstvo/glass/define once makes both tags work on the page.

TagWhat it is
edinstvo-glassOne piece of glass. Anything you put inside it is shown on top of the glass
edinstvo-glass-groupA wrapper. Settings on it reach every piece inside, and pieces inside can merge

  Takes frost from the group
  Uses its own

Attributes

Look settings are listed in Material, Lighting and Motion. These are the rest.

AttributeWhat it does
sourceWhat the glass shows behind it: a CSS selector such as #photo. Leave it out and glass looks for it by itself
liveRedraw on every frame. Needed for a canvas that changes all the time. It costs more, so use it only there
appearFade the glass in when it reaches the page
layerA number. Higher glass sits on top and sees the glass below it

Properties

PropertyWhat it takes
materialAn object of settings. Attributes win over it
sourceSame as the attribute, and also an image, video or canvas element
const glass = document.querySelector("edinstvo-glass");

glass.material = { frost: 0.2, tint: "#e54d33" };
glass.source = document.querySelector("video");

Methods

MethodWhat it does
invalidate()Redraws the glass once. Call it after you draw on a canvas behind it
show()Makes the glass appear. Returns a promise that ends with the animation
hide()Makes it vanish, the same way
await glass.hide();
glass.remove();

CSS variables

Any setting can come from CSS, which is handy for themes. Add --glass- before its name. The value is passed down to everything inside, like any CSS variable.

:root {
  --glass-frost: 0.4;
  --glass-light-color: #fff3e0;
  --glass-radius: 20px;
}
VariableWhat it does
--glass-radiusCorner radius
--glass-shadowShadow under the glass
--glass-fallbackFill used when WebGL isn't available

Functions

Import these from @edinstvo/glass when you need them.

FunctionWhat it does
setSceneLight(light)Sets the light for the whole page. Only the settings you pass change. null clears it
attachGlass(element, options)Turns any element into glass without a custom tag
defineGlass(name)Registers the tags under your own name
resolveMaterial(...layers)Returns the final settings after stacking layers
resolveMotion(...layers)The same for motion
import { attachGlass, defineGlass, setSceneLight } from "@edinstvo/glass";

setSceneLight({ direction: "top-left", intensity: "80%" });

defineGlass("my-glass"); //  and 

const glass = attachGlass(document.querySelector(".panel"), {
  material: { frost: 0.3 },
  source: "#photo",
});

glass.set({ material: { frost: 0.6 } });
glass.destroy();

attachGlass takes material, motion, source, live and appear. It returns an object with set, invalidate, show, hide and destroy. Call destroy when the element goes away.
