A CSS gradient looks like an image, but glass can't read it yet. It skips the gradient and looks further down the stack. There are two easy ways around it.

Draw it on a canvas

The canvas API has gradients too, and glass reads a canvas.

const context = canvas.getContext("2d");
const gradient = context.createLinearGradient(0, 0, canvas.width, canvas.height);
gradient.addColorStop(0, "#e54d33");
gradient.addColorStop(1, "#2244cc");
context.fillStyle = gradient;
context.fillRect(0, 0, canvas.width, canvas.height);

glass.invalidate();

Use an image

Export the gradient as an image and set it with url() or an <img>. It is the simplest way if the gradient never changes.
