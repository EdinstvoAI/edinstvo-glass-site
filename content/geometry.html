Available shapes

ValueGeometry
rounded-rectDefault; follows the CSS corner radius.
circleInscribed in the shorter side of the element.
ellipseSpans the element width and height.
superellipseContinuous curve; curvature 2–8, default 4.
pathSVG path mapped from a view box.

JavaScript API

const surface = attachGlass(element, {
  geometry: { shape: "path", path: "M50 0L100 100H0Z", viewBox: [0, 0, 100, 100] },
  material: { depth: 12, refraction: 0.4 },
});
surface.set({ geometry: { shape: "ellipse" } });
glassElement.geometry = { shape: "superellipse", curvature: 6 };

Contours and normals affect refraction, dispersion, light, rim and reflection. Shapes participate in existing merging and layers. A merged group shares a material, while its individual contours can differ.

SVG data and limits

Only path data is accepted: no SVG markup, scripts or external resources. Limits are 64 KiB, 4096 commands and finite coordinates within ±1,000,000. Each path uses a cached 256×256 distance tile. Normal interaction does not rebuild it.

Small details, concave contours and extreme scaling may show sampling artifacts. HTML layout and hit testing remain rectangular; content is not automatically clipped. Custom paths have no automatic box shadow. CSS fallback retains an ordinary rounded rectangle.
