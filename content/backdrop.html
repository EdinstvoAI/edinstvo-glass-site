WebGL can't read the pixels of a page, so glass has to be told what is behind it.

Automatic

By default it looks under itself and takes the nearest <img>, <video>, <canvas>, CSS url() background, gradient or solid colour.

By hand

glass.source = canvas;
glass.invalidate();

Things that change

A playing video updates on its own. If you draw on a canvas, call invalidate() after drawing, or add live to redraw every frame.

When the backdrop can't be read

If glass looks flat, it found only a solid colour. Put an image, video or canvas under it, or pass one with source.

If it turned into plain blur, that is the CSS fallback. Either WebGL is off, or the image comes from another domain without CORS. The browser console says which.
