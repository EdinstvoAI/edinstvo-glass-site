Glass can sit on glass. This page explains who sees whom.

The rule

Each glass element is a layer. A layer sees everything below it, including other glass, and nothing above it. So a small button on a glass card bends the card, and the card doesn't know the button exists.

Who is on top

By default the later element in the document is higher. To set the order yourself, use layer. A higher number is on top, and it works like z-index.

How it works

Before drawing, a layer takes its backdrop and paints the finished glass below it on top. Then it bends that picture. When a lower layer changes, the ones above redraw too.

Groups

Glass inside a group that merges is one surface, so it is one layer. A child that doesn't merge stays its own surface and can have its own layer.

Things to watch

layer compares numbers across the whole page and doesn't look at nested CSS stacking contexts. If an element looks on top but bends as if it is below, set layer on both.
