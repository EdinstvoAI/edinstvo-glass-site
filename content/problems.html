The usual suspects, with the fix for each.

The glass looks flat

It found nothing but a solid colour behind it. Put an image, video or canvas under the element, or pass one with source.

Nothing shows up

Check that the element has a size. An empty tag with no width and height is 0 by 0 and draws nothing.

The canvas behind doesn't update

Glass doesn't know you drew something. Call invalidate() after drawing, or add live.

It turned into plain blur

That is the CSS fallback. Either WebGL is off, or the backdrop is a cross-origin image without CORS headers. The console says which.

Text inside is hard to read

Glass goes over anything, so contrast is on you. Raise frost and lower transparency behind text.

Too many elements

A still page costs nothing, only what moves is redrawn. If a long list scrolls slowly, use the plain CSS classes for the small pieces.
